# 这些规矩各自防的是什么

> 每条 = 规则 → 它防的事故 → 怎么判定。
> 只收「换一个维护者也要照做」的条目。凡是听起来像建议的，都已经删掉了。

## 零、总纲：三条元规则

1. **守卫的价值不在于证明自己对，而在于证明自己没写坏。**
   一条问错问题的守卫，比没有守卫更危险 —— 它会给人虚假的安全感。
2. **文档同步可以反方向发生，判据永远是「哪一边与代码一致」，不是「谁是权威」。**
   机械地以「归档文档」为准，会把正确的镜像改错。
3. **任何「必须满足」的不变量，都要配一条会红的断言，而不是一句注释。**
   写在注释里的铁律没有执行者；踩了几个月也不会有人发现。

## 一、文件形态（行尾 / BOM / 编码）

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 每个文件有**自己的**形态基线，改前后必须守恒 | 整个文件 diff、发布后页面诡异损坏 | `lineendings.js verify` 退出码 0 |
| 形态要**现场量**，不靠记忆 | 基线记的是三个月前的状态，改完自以为没变 | 先 `report` 再 `snapshot` |
| BOM 数**个数**，不判**有无** | N 个连续 BOM 被合并成 1 个，boolean 守卫判 PASS | `BOMx<N>` 里的 N 不变 |
| 「混合行尾」先判是不是某个工具的**确定性产物** | 把结构性不变量当污染去修 ⇒ 整文件 diff | 跑一遍那个生成器，看形态是否可复现 |
| 混合行尾一旦被抹平**不可重建** | 处置方式只剩「钉死当前基线」 | 破坏后只能从备份恢复 |
| 重组文件时把行尾当一等公民 | 用单一 EOL 重拼全文 ⇒ 全文件 diff | `split(/(?<=\n)/)` 保留每行终止符再 `join('')` |
| 判据比**形态**，不比行数 | 本轮本来就要加行/删行，比行数必然误报 | 只比 pure-CRLF / pure-LF / MIXED + 末尾换行 |

## 二、改文件的方式

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 绝不手工编辑行尾敏感文件 | 编辑器自动「统一行尾」，一次改动数百行 | 改动只经补丁脚本 |
| 锚点逐字取自磁盘且**全局唯一** | 改到别处，静默成功 | `split(anchor).length - 1 === 预期` |
| 命中 0 或 >1 立刻中止，**不写盘** | 磁盘停在半应用状态 | 退出码非 0 |
| **所有锚点在任何写盘之前预检完** | 前一步已落盘、后面失配，无法回滚 | 预检全绿才进写盘 |
| 幂等判据由作者**显式声明**（`already`） | 拿 replace 自动猜，短文本误命中 ⇒ 失配被当成「已落盘」，静默跳过还写盘 | 不填 `already` 就 FAIL |
| 锚点唯一性断言**是恒真的** | 它证明不了任何事，脚本打印三次 ✅ 而文件一字未改 | 必须再加「替换真的生效」那条 |
| 编号类替换带上下文锚点、整串替换 | `#186` 改到别人源码里对方的注释 | 锚点里含足够上下文 |
| 写盘后**回读**再断言一次 | 内存副本断言全 PASS 而文件根本没落盘 | 回读字符串 === 内存字符串 |
| 正则替换文本里不得出现 `$`；替换后跑结构自检 + 语法检查 | 捕获组错位、闭合标签被吃掉 | `node --check` + 开合标签逐张核对 |
| 长文本走独立 `.txt` 读入 | 中文里的反引号 / ASCII 单引号截断字符串字面量 | 正文不进源码字面量 |
| 落盘脚本的 stdout 不要接进会提前关闭的管道 | 提前关管道 ⇒ EPIPE ⇒ 脚本中途死亡，目标文件被截断 | 完整读取输出 |
| 批量替换先在副本上试跑，输出只打汇总 | 逐文件打 PASS 撑爆输出，进程被杀，后 N 个文件根本没改 | 汇总式输出 + 改完逐文件复核残留 |

## 三、断言与探针

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 断言必须能对**它声称验证的那件事**失败 | 断言比较的东西与 bug 无关 ⇒ 永远绿 | 故意做坏样本，它必须红（负向对照） |
| 断言的输入是**当场实测**的量 | 断言前提早已过期，校验降级成摆设 | 写之前跑一次取值 |
| 禁止写死会增长的计数，改关系式 | 加一条数据 ⇒ 假红一批，还常被误判成回归 | `A === B` 而非 `=== 16` |
| 计数用 **eval 取数据**，不用正则扫文本 | 正则把注释里的条目也算进去，口径错 | eval 出来的长度 |
| 存在性 ≠ 内容 / 布局 | 元素在 DOM 里、样式全对、事件也绑着，却被 `clip-path` 裁掉不可点 | 量计算后的几何 |
| 探针**不许吞异常** | `try{}catch{}` 让整套件静默测十几轮死数据 | 异常必须冒泡成 FAIL |
| 测量前先等元素有非零宽度 | 隐藏状态下取到未解析的指定值，列数误报 | 轮询判据，不用固定 sleep |
| 零宽元素优先判为**探针**问题 | 把好代码改坏 | 先证明探针是对的 |
| 探针选择器按**真实 DOM** 推导 | 按名字猜 ⇒ 一上来就假红 | 照抄实现里的 class / id |
| 会移动 DOM 的浮层用 id，不用 class | 同名 class 有两个，选到空的那个 | `#id` |
| 探针要覆盖集合里的**每一类成员** | 只测第一项而它恰好是特例，其余从未被测 | 遍历类别 |
| 探针不采信页面自报的数 | 探针只是在验证实现对自己的复述 | 从原始数据独立重算 |
| 只改注释/文案时，断言「代码区逐字节未变」 | 改坏功能而自认没动代码 | 剥注释后逐字节比 |
| 守卫要**双向**测：应抓的全中、不该抓的不误报 | 漏报与误报同等致命 | 正样本 + 负样本 |
| 守卫判据按**语境**收窄，不按字面 | 过宽的守卫第一天就红，然后被人随手删掉 | 白名单从原始备份自动推导 |
| 守卫不得写死数据文件名 | 改名后悄悄失效 | 找不到文件时**报错**而非跳过 |
| 「文件存在」要逐字比对目录项 | 大小写不敏感的系统上通过，Linux 线上 404 | 大小写敏感比对 |

## 四、回归

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 红了先问「前提过期」还是「实现坏了」 | 把「改探针」当成「修 bug」，真回归被掩盖 | 读实现的判据 |
| 动探针前先读实现 | 「改探针」可能掩盖真问题 | 实现是对的才改探针 |
| 每个套件跑**两条协议**（http + file） | `file://` 下 CSSOM opaque、fetch 被 CORS 挡、ES Module 不可用 | 双协议都跑 |
| 跑批器**串行** | 多套浏览器同开互抢 CPU，计时失真、偶发假红 | 顺序执行 |
| 每套跑完**立刻**落盘日志 | 进程被杀时缓冲全丢，跑到第几套都查不到 | `appendFileSync` |
| 失败重跑一次，抖动单独标出并**保留首跑失败行** | 重跑覆盖首跑，「首跑为什么红」彻底丢失 | 汇总里两行都在 |
| 判抖动先看双协议是否一红一绿 | 环境问题被误判成实现问题 | `[http]` 红 `[file]` 绿 ⇒ 环境 |
| 套件数变更要同步改掉写死的套件数断言 | 新套件加入 ⇒ 日志校验自己变红 | 跑批器里的 N 同步 |
| 超时不许被 `.catch(()=>{})` 吞掉 | 假红伪装成真 bug | 等待按实测最坏给 |
| 等状态，不用固定 `waitForTimeout` | 负载高时假红，重跑仍红被误判真失败 | `waitForFunction` |
| 棘轮基线是**快照**，不追移动目标 | 并发在途时计数自己会变 | 收工后一次性校准 |
| 用户拍板的锁**不是基线** | 自己抬了就等于替用户改规则 | 抬它要用户点头 |

## 五、数字与事实

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 刷数字按**数字模式全局扫**，不按行号清单 | 行号清单漏掉的永远不会自己变绿 | 正则扫全库命中点 |
| 先判「当前态」还是「历史」 | 把历史章改成今天的数 = 销毁证据 | 「这句话会不会随今天的文件变」 |
| 计数用 eval，差值要**实测集合** | 两个数相减得出「差 23」，实际集合是另一个数 | 直接算集合 |
| 数字现场实测后写入 | 估算 / 抄上次的值 | 写之前同脚本量一遍并断言相等 |
| 体积取文件实测字节 | 估算偏差 | `statSync().size` |
| 会变的数字不进对外声明（title / description / 分享卡） | 声明过期无人查 | 只写不含数字的表述 |
| 没有的数据不画成 0 | 缺失被读成「实测为 0」 | 显式标注缺失 |
| 代理 / 推断数据必须显式声明来源 | 读者以为是本场实测 | 字段名 + note 双标注 |
| 位图不是数据源 | 像素反推的近似值会被当数据读，比没有更糟 | 摆原图 + 说明，不列统计项 |
| 缺字段宁缺勿猜 | 编造的年月 / 作者 / 链接比没有更糟 | 留空 |

## 六、文档

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 双轨：读者文档 vs 归档文档，各管各的 | 两类读者混用一份，两边都不好用 | 见 `doc-contract.md` |
| 文档头注格式双向同步 | 改一边另一边错位 | 改任一份就 grep 另一份 |
| 「当前状态」章是**快照**，不是追加日志 | 快照章自己长爆，比它要回答的问题还大 | 每轮改这一章，不另起 |
| 加章时同时改索引表 + 模块表 + 开放项 | 索引落后于目录，快照章自己变成「过期的那半」 | 三处一起改 |
| 历史章一字不删不改，只加指针 | 后来者照着已失效的建议抄 | 章首加「勿据此改代码」 |
| 「已并入 X」这类声称要验证 X 真的存在 | 声称式归档留下静默信息黑洞 | 打开 X 找那段 |
| 目录表由脚本重生成，不手改 | 手改清单在几次拆文件后悄悄漂移 | 跑生成器 |
| 新章只取空号，不重编号 | 全局替换改到别人的记录 | 先算准区间并断言区间内无他人内容 |
| 「已同步 / 已完成」这类状态陈述本身要被校验 | 探针只测运行时，不测文档里的进度陈述 | 读者对账才发现数不上 |
| 本轮没新增就明写「无新增」 | 为凑数硬写，日志失去信号价值 | 明写 |

## 七、发布与泄露面

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| **工作目录就是部署根目录** ⇒ 根目录一切都会上线 | 内部文档被当静态文件发布出去 | `deploy-audit.js` |
| 必须有一份**显式排除清单**，且它自己也要被排除 | 清单本身泄露内部结构 | 清单里包含它自己 |
| 内部工作文档绝不能上线 | 含决策与联系方式的文档可被直接下载，并可能被搜索引擎收录 | 扫描 + 远端删除 |
| 从远端**删除**对象才算修完 | 「以后不上传」不等于旧的没了 | 逐个 URL 实测非 200 |
| `robots.txt` 是建议不是权限 | 它不能让**已被索引**的页面消失 | 需要搜索引擎侧的移除请求 |
| 首页不得有指向内部文档的可点链接、不得出现本机绝对路径 | 爬虫顺着链接就能拖走 | 扫 `<a href>` 与路径形态 |
| 注释区也是防线 | 注释里复述敏感值 / 写部署指纹 | 守卫要扫注释，且按「会发布的文件类型」逐一覆盖 |
| 缓存策略选「内容变了 URL 就变」，不是「改 TTL」 | 边缘拿旧副本应答 | 版本号 / hash 查询串，且**引用处全改**（HTML、CSS `url()`、JS 拼的 URL，一处漏了就是一半新一半旧） |
| 发布后做一致性核对，且**必须走 http** | `file://` 下 CSSOM opaque，两边都空等于没查 | 检查器退出码 0 |
| 比对线上文件走**二进制** | 文本管道把 UTF-8 当 Latin-1 解，差分结论全假 | 读 buffer 比 hash |
| 「文件逐字节相同」≠「浏览器实际拿到的那份相同」 | 缓存 / 压缩分桶 / CDN 边缘 | 看响应头与实际字节数 |
| 静态托管下不存在真正的保密 | 藏法只对「批量正则采集」有效 | 别把安全建立在隐藏路径上 |

## 八、并发与协作

| 规则 | 防的事故 | 判定 |
| --- | --- | --- |
| 清理目录的判据是「**有没有另一个活跃写入者**」，不是「是不是临时文件」 | 看起来是垃圾的东西正被另一会话读着 | 问清楚再删 |
| 删除前先 grep 引用数 | 被几十处引用、且文档标注「勿删」的文件不是过程文件 | 引用计数 |
| 一次性产物与可复用验证套件分开放 | 回归要重跑的套件被当垃圾清掉 | 分目录 |
| 改文件不要在回归跑到一半时做 | 探针读到半应用状态 | 等跑批结束 |

## 九、本类项目最隐蔽的一种故障

**文件被同步盘 / 云盘静默回退成旧版。**

它不报错、不留痕、页面也不白屏，只是某个模块悄悄退回旧样子。

识别线索，按可靠性排序：

1. **mtime 早于改动日** —— 最硬的证据；
2. **「只坏一个文件」** —— 回退的指纹；真 bug 很少这么整齐；
3. **文档记过改法，但实现里没有** —— 说明不是「没做完」，而是「做完了又没了」。

处置：从副本恢复或重放原补丁，**不要重新发明一遍**。重写会在别处引入新差异。

预防：每轮回归**真跑**，不能靠「上一轮是绿的」推断。在同步盘上尤其如此。
